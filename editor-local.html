VM INOVART · Gerenciador local de produtos

Ferramenta auxiliar para manter o catálogo sem editar código. As alterações aqui NÃO são publicadas até substituir o arquivo no GitHub. A fotografia publicada deve ser a arte completa original, sem cortes, filtros ou alterações.

Cadastrar produto

Envie sempre o PNG/JPG original, sem recortar ou reexportar. O arquivo deve existir na pasta assets/produtos. Não basta informar o nome.

Produtos cadastrados

Clique em Editar. O sistema evita códigos duplicados.

Como colocar as mudanças no catálogo online

  1. Adicione ou edite os produtos nesta ferramenta.
  2. Baixe o arquivo produtos.js atualizado.
  3. No GitHub, abra seu repositório de catálogo e substitua data/produtos.js pelo arquivo baixado.
  4. Se houver foto nova, inclua o arquivo indicado em assets/produtos/ no mesmo repositório.
  5. O GitHub Pages publicará a atualização após o commit.

Este editor utiliza armazenamento local do navegador para manter o rascunho. O arquivo exportado é a cópia segura que deve ser guardada. Ele não funciona como painel administrativo conectado ao servidor.
